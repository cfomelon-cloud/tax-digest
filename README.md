# Private Client Tax Digest

A static website of daily cross-border private-client tax digests, hosted on GitHub Pages.
Live site: https://cfomelon-cloud.github.io/tax-digest/

## Structure

```
index.html              <- homepage, auto-generated by build_index.py (DO NOT hand-edit)
style.css               <- shared styling for all pages
build_index.py          <- regenerates index.html from data/manifest.json
data/manifest.json      <- list of editions: [{date, file, headline, blurb}, ...]
digests/YYYY-MM-DD.html  <- one self-contained page per daily edition
```

## How a new daily edition is added (automation)

1. Create `digests/YYYY-MM-DD.html` (self-contained; link `../style.css`).
2. Prepend a new entry to the array in `data/manifest.json` (`date`, `file`, `headline`, `blurb`).
3. Run `python3 build_index.py` to regenerate `index.html`.
4. Commit and push to `main`. GitHub Pages redeploys automatically.

Jurisdictions — priority: UK, US, China, Hong Kong, Singapore.
Secondary: Italy, Portugal, Australia, Canada, Taiwan.
